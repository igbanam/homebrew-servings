# mamiwota

Renders Mermaid diagrams as ASCII art in the terminal.

## Installation

```
brew tap igbanam/dev-tools
brew install mamiwota
```

## Usage

```
Usage:
  mamiwota <filename.mmd>
  mamiwota [options]

Options:
  -h, --help     Show this help message
  -v, --version  Show version
```

Supported Diagram Types:
  - sequenceDiagram  Sequence diagrams with messages, notes, loops, etc.
  - classDiagram     Class diagrams with classes, relationships, etc.
